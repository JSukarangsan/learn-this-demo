## Unclassified (1)

`Home / desktop / logged-in` — `9:85`

`logged-in` is auth vocabulary; the glossary is entitlement vocabulary. It maps to
self-serve **or** assigned, so it is not resolved here. It matters because the pricing rule
rides on that distinction.

Circumstantially there is a separate `Home / desktop / assigned` (`20:2`), which suggests
`9:85` was meant as self-serve — but the frame doesn't say so, and its content ("Welcome
back, Priyanka", upcoming session, progress) is true of both. Renaming it to a glossary
state disambiguates it.

Until then **desktop · self-serve · default has no unambiguous frame**, though it looks
covered.

The two `logged-out` frames (`9:2`, `9:124`) map cleanly to **anonymous** — one canonical
state, so they were mapped — but anonymous is out of scope here. See N/A.

## Missing (16)

Ranked by the layer's own evidence.

**assigned · empty — desktop-1024, mobile-320**
Every designed no-session card routes to "Browse courses" (`20:58`, `20:97`, `21:66`). For
an assigned learner that path ends at the catalog, and both `product/glossary.md` and
`design/CLAUDE.md` name showing a price to someone who can't buy as the top org-admin
complaint. The rule is most likely to break in exactly the cell that doesn't exist.

**lapsed · empty — desktop-1024, mobile-320**
Lapsed is the glossary's "most-forgotten state — they land on screens nobody designed for
them." The lapsed frames promise "Recordings stay available for 12 months" (`20:57`,
`21:65`), which defines a moment when the recordings row goes empty. Nothing is designed
for after it. Empty copy is design's to write, not product's.

### Axis-level gap

`tokens.json` defines four breakpoints — 320, 480, 768, 1024. The file uses two. **480 and
768 are undesigned for all 12 signed-in cells each** (24 more). This may be a deliberate
two-viewport practice rather than a gap, but the token file is where the axis comes from.

## N/A (3 groups)

**anonymous × all conditions × all viewports (8 cells)** — `product/glossary.md` defines
anonymous as "not signed in." A signed-in home doesn't owe it. `9:2` and `9:124` cover the
anonymous home, a different screen.

**any countdown variant of the upcoming-session card** — `design/CLAUDE.md`: "Never put a
countdown on a live session." Tried it; instructors hated it. The existing "Starts in 2
days" tag is a relative date, not a countdown — the forbidden thing is the ticking
treatment. Forbidden, not missing.

**offline condition** — `product/decisions/2026-07-02-offline-mode.md`, status `proposed`,
and Instructor Tools hasn't agreed. Not a condition this screen owes today.

## Accessibility — unverified on all 8 signed-in frames

Nothing in the Figma file records contrast, focus order, or labels. Layer names, structure,
and geometry are readable; contrast and focus order are not. This is a gap in the file, not
in this report.

Two things that **are** readable, both conformance misses worth checking:

- **`button-primary` min-height is 44 in `tokens.json`.** The signed-in mobile nav buttons
  are 40 — `21:7`, `21:33`, `21:59`, all three 320 frames. A touch target, so not only a
  token nit.
- **`session-card` `must-show` lists cohort timezone *and* instructor name.** Timezone is
  present everywhere and correct per the 2026-08-04 decision. Instructor name is absent
  from every signed-in upcoming card — `9:85`, `20:2`, `21:2`, `21:28`. Confirm whether the
  `upcoming` frame counts as a session-card before treating it as a violation.
