# Session list — states

Scoped to the schedule screens in this project. The rules these are built against live in
`../../../../design/CLAUDE.md` and `../../../../design/tokens.json`, and they are not
restated here.

The squad-wide coverage matrix is `../../../../design/states/`, generated by
`/states-table`. **This file is different in kind:** it is authored, it covers only the
screens this project adds, and it records decisions rather than coverage.

## The four learner states don't all apply

`../../../../product/glossary.md` names four — anonymous, self-serve, assigned, lapsed.
The schedule screens owe three of them.

| State | Sees the session list | Why |
|---|---|---|
| anonymous | no | Not enrolled, so there is no cohort to have a schedule |
| self-serve | yes | |
| assigned | yes | |
| lapsed | **yes, and this is the one we nearly missed** | A lapsed learner keeps recordings for 12 months. They still have a schedule; it's just entirely in the past |

## Decided here

**Times render in the cohort's timezone, with the abbreviation always visible.** Never the
browser's, never a "your time" conversion. A live session is a single moment, and two
learners seeing two different times for it means one of them is wrong and neither can tell
which. The abbreviation is not decoration — it is the only thing on screen that tells a
learner in Denver that 15:00 is Lisbon's 15:00.

**No countdown.** `../../../../design/CLAUDE.md` forbids the ticking treatment on a live
session. "Starts in 2 days" is a relative date and is fine; the thing that ticks is not.

**Past sessions stay in the list, greyed, above a rule.** Removing them makes a lapsed
learner's schedule screen empty, and empty reads as broken.

## Known gaps, and they are gaps

**The empty state for a lapsed learner past 12 months is not designed.** When the
recordings expire the list has nothing in it and nothing is drawn for that. It's tracked —
`SCRUM-16` — which is more than can be said for most of the states audit.

**Nothing here is verified for contrast or focus order.** Layer names and geometry are
readable from the file; contrast is not. Same limitation as the generated matrix upstairs,
stated for the same reason: an unverified pass looks identical to a pass.

**320 is not done.** `../../../../design/CLAUDE.md` puts roughly 40% of attendance on a
phone and names 320 as the second-most-common width. The session list has a desktop frame
and no 320 frame, which makes it the same gap the states audit found across the product.
